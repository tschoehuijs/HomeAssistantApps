## 2.2.3

# Tracearr v2.2.3

- merged users no longer split apart on the next stream
- legacy Plex owner accounts repaired on first boot
- music library sync no longer dies on null bytes in ID3 tags
- map no longer takes the app down when the browser blocks WebGL
- pages fail on their own instead of blanking the whole app
- stale tabs reload after an upgrade instead of dying on a missing chunk
- browser errors show up on the Debug page
- banner when a volume is mounted over a bundled path

Other release notes: https://github.com/connorgallopo/Tracearr/releases/tag/v2.2.0
