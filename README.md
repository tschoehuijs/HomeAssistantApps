### Installation
To add this repository and install the apps in Home Assistant, follow these steps:

1. Open Home Assistant and navigate to **Settings** > **Add-ons**.
2. Click the **ADD-ON STORE** button in the bottom right corner.
3. Click the three vertical dots (menu) in the top right corner and select **Repositories**.
4. Paste the URL of this GitHub repository into the input field and click **Add**.
5. Close the dialog. Click the three dots in the top right again and select **Reload**.
6. Scroll down to the bottom of the store to find this repository and its add-ons.
7. Click on the app you want (Wizarr, Tracearr, or Chaptarr) and click **Install**. 
8. Once installed, review the **Configuration** tab before clicking **Start**. In my experience the apps work fine as-is.
